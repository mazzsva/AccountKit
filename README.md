# AccountKit

Sign in with Apple account flow in TCA, Firebase Auth, and Firestore.

AccountKit is in development. It will hold the account code that Lexicon and Overhead share: Sign in with Apple, Firebase Auth, Firestore storage, the session, sign-in, account deletion, and the account settings logic. It has no UI.
